# Metrics

The seven governed metrics, each backed by an attested computation:

- [Net Bookings USD](/metrics/net-bookings-usd.md) — the headline metric;
  what "bookings" means by default.
- [Positive Booking Movements USD](/metrics/positive-booking-movements-usd.md)
  — analytical diagnostic; **not** Gross New Bookings.
- [De-bookings USD](/metrics/debookings-usd.md) — negative movements,
  signed.
- [Cancellation De-bookings USD](/metrics/cancellation-debookings-usd.md)
  — the CANCEL subset.
- [Transaction Booking Amount](/metrics/transaction-booking-amount.md) —
  single-currency transaction amounts.
- [Transaction Booking Amount With Tax](/metrics/transaction-booking-amount-with-tax.md)
  — tax-inclusive twin.
- [Distinct Sales Orders](/metrics/distinct-sales-orders.md) — order
  counts.
